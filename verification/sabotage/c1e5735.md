## Summary

**Adversary probes catch 5 of 14 original mutants + 2 of 3 additional = 7 of 17 tested**

**Genuinely uncovered by adversary probes (require new probes):**

1. **M2** (R006): Wall-clock occupancy comparison — masked by single-timezone fixture
2. **M3** (R054): Fall-back resolves to second occurrence — no probe tests this
3. **M7** (R041/R007): Receipt stored on 4xx failure — probe R007 tests different defect
4. **M14** (R049): Sort by local time string — masked by single-timezone fixture (same root cause as M2)
5. **Non-atomic idempotency** (R040): Lookup/remember gap — probe R005 doesn't exercise it
6. **Null replay** (R041): Replay returns null — probe R041 may not assert strictly enough
7. **Fabricated instant for skipped time** (R053): Spring-forward booking allowed — probe R053 may not assert strictly enough

**Root cause duplication:** M2 and M14 share one root cause (fixture never leaves Europe/Berlin). One probe covering cross-timezone sort/occupancy would catch both.
